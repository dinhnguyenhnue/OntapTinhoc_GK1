# Cổng Ôn Tập Tin Học Giữa Kì 1 (GK1) - UNIGO

Website ôn tập trắc nghiệm và kiến thức Tin học dành cho học sinh từ **Lớp 3 đến Lớp 8** trường UNIGO.

## 🚀 Tính năng nổi bật
- Đầy đủ ngân hàng câu hỏi ôn tập định kỳ 1 (Giữa kì 1) cho tất cả các khối lớp 3, 4, 5, 6, 7, 8.
- Chấm điểm tự động, phản hồi giải thích chi tiết ngay sau mỗi câu trả lời.
- Giao diện trực quan, thân thiện, tối ưu hiển thị mượt mà trên cả máy tính, máy tính bảng và điện thoại.
